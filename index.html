GNN vs. Transformer for Road Network Trajectory Prediction

GraphSAGE · Transformers · Self-Attention · PyTorch · OpenStreetMap

Built an end-to-end comparative ML system on real-world map data (~2K nodes, ~5K edges from OpenStreetMap). Generated realistic movement trajectories via random walk simulation to model road traffic behaviour. Implemented GraphSAGE to capture spatial node relationships and a Transformer with self-attention to model sequential patterns with full training pipelines, cross-entropy loss, and evaluation on next-node prediction accuracy.

Key finding: Transformers outperformed GNNs on sequential trajectory dependencies; GNNs captured structural road graph relationships more effectively providing empirical guidance for architecture selection in autonomous driving and spatial AI systems where both spatial context and temporal sequence must be modelled simultaneously.

QUANT FINANCE · MULTI-ASSET

Financial Time-Series Forecasting Pipeline SPY, QQQ & Equities

LSTM · XGBoost · Logistic Regression · Streamlit · Walk-Forward Validation

Full-stack quantitative ML pipeline for next-day and 3-day price direction prediction across multiple tickers (SPY, QQQ, individual equities). Engineered 55+ leakage-free technical and regime-context features (VIX relative to trailing median, drawdown-from-high, bull/bear trend flag, RSI, MACD, Bollinger Bands) using only information available at market close. Benchmarked Logistic Regression, XGBoost, and LSTM head-to-head on identical expanding-window walk-forward folds with embargo/purge gaps every model compared against a mandatory majority-class baseline. Full backtesting engine with transaction costs, Sharpe ratio, and drawdown metrics; three position-sizing overlays evaluated empirically. Interactive Streamlit dashboard with live per-ticker model training, walk-forward evaluation, and predictions on demand.

Honest result: Walk-forward AUC ~0.50–0.54 a small, inconsistent edge over a naive baseline, reported as-is. A model with decent classification accuracy can still produce a negative post-cost Sharpe ratio; that combination is a valid finding, not something to explain away.
